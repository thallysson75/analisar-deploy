# Cadastro de Usuários Simples

Projeto de estudos em Python. Permite cadastrar, listar, buscar e excluir
usuários. Os dados ficam em memória e são apagados quando o programa termina.

## Requisitos
- Python 3.10 ou superior

## Executar
```bash
python main.py
```

## Instalar pytest e testar
```bash
python -m pip install -r requirements.txt
python -m pytest -v
```

O GitHub Actions executa os testes automaticamente a cada push e pull request.
